# tg-bot-mora

# 🤖 Telegram Bot с кошачьим акцентом + AI + новости

Бот для Telegram, который отвечает на вопросы с помощью **Groq AI (Llama 3)** и имеет **милый кошачий акцент**. Каждый день в 10:50 отправляет свежие новости из мира AI с Хабра.

## ✨ Возможности

- 🐱 **Кошачий акцент** — все ответы с "мяу" и "мур"
- 🧠 **Умные ответы** — интеграция с Groq API (модель Llama 3)
- 📰 **Ежедневные новости** — рассылка в 10:50 из RSS Хабра (раздел AI)
- 🔍 **Режим работы:**
  - В личных сообщениях — отвечает на любой текст
  - В группах — реагирует только на упоминание @бота
- 📊 **Команды:**
  - `/ask вопрос` — спросить AI
  - `/compare X vs Y` — сравнить технологии
  - `/news` — получить новости прямо сейчас

## 🛠 Технологии

- Python 3.10+
- Aiogram 3.x
- Groq API (Llama 3)
- Feedparser (RSS)
- Python-dotenv
